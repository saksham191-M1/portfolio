PROJECT SUMMARY

LIVE EXECUTION LAYER

Scoupe is a developer tool that wraps around any AI coding assistant (GPT-4, Claude, Gemini, Codex) and enforces professional software engineering standards—automatically.

It eliminates the most frequent and costly failure modes of AI-assisted engineering: scope creep, broken partial rollbacks, silent file corruption, and arbitrary violations of team conventions.

Scoupe is not a linter and not a passive code review tool. It is a live execution layer sitting directly between developer intent and LLM tool execution—observing, controlling, and rolling back file writes in real time.

THE CORE DISTINCTION

EXECUTION LAYER VS. PROMPT HOPE

Existing solutions rely on system prompts or markdown files like CLAUDE.md that LLMs frequently ignore under long contexts. Scoupe enforces boundaries cryptographically at the execution boundary.

Scope Creep AI touches unrelated files, rewrites imports, or breaks surrounding architecture it was never asked to touch. ✕ Not Caught ✓ Scope Lock Contract Blocks unauthorized file access prior to write.
Partial Writes Developer cancels mid-stream; half-written methods or broken syntax are left stranded in repository files. ✕ Not Caught ✓ Hot Task Queue Instant zero-friction rollback to pre-task snapshot.
Context Explosion LLM greedily reads 15+ files to locate one utility function, draining tokens and polluting context window. ✕ Not Caught ✓ Graphiti MCP Knowledge-graph queries reduce tokens by 5x–70x.

KEY INNOVATIONS

ENGINEERING ARCHITECTURE
INNOVATION 01SYSTEMS GATEWAY

1. 🔒 Scope Lock Engine

Instead of hoping the LLM stays in bounds, Scoupe executes an automated 5-question pre-task interview with the developer. The answers generate a deterministic Scope Contract in JSON format:

  • Whitelisted File Paths: Exactly which paths the AI is authorized to create or modify.
  • Boundary Definition: Strict negative criteria ("What this task is NOT allowed to change").
  • Acceptance Criteria: Quantifiable verification checklist for task completion.

This contract is dual-injected: fed into the LLM system prompt and applied as an output-level filter before file write operations touch disk. The model physically cannot write outside the boundary.

Honest Engineering: This is designed as clean output-level filtering rather than unviable OS sandbox blocking—delivering robust cross-platform safety.
INNOVATION 02ORCHESTRATION

2. 🔥 Hot Task Queue with Auto-Rollback

Scoupe manages an orchestrator-side queue where the LLM only ever receives a clean, isolated context for one discrete sub-task at a time.

01 Task Starts → File Snapshot Cached
→
02 User Stops / Error → Instant Rollback
→
03 Task Completed → Summarized for Next Context

Same-File Conflict Detection: When two queued tasks target overlapping files, Scoupe warns the engineer beforehand rather than allowing destructive clobbers, fostering intentional codebase architecture.

INNOVATION 03PIPELINE VALIDATION

3. 🧠 3-Layer Error Scanner

Every generated output passes through three tiers of verification ordered strictly by computational cost:

LAYER 1

Regex Scanner

Runs on every streamed token in real time; catches syntax leakages, API keys, and forbidden pattern tokens with near-zero latency.

LAYER 2

AST Parser (Tree-sitter)

Executes once per completed file write. Eliminates false positives by parsing complete syntax trees across 150+ languages.

LAYER 3

Semantic AI Evaluator

Only fires conditionally when Layer 1 or 2 flags an anomaly. Clean files never hit this layer, conserving tokens and compute.

INNOVATION 04OBSERVABILITY

4. 📋 Live Manifest Engine

Every file touched during an AI session is tracked live through a 6-state finite state machine over WebSocket/SSE:

CHANGED Modified ADDED Created PENDING Streaming SKIPPED Untouched FLAGGED Issue Detected LOCKED Access Denied

Backed by an append-only session store JSON, developers maintain 100% visibility over filesystem alterations at every tick.

INNOVATION 05CONVENTIONS

5. 🎓 Professional Standards Engine (PSE)

Enforces enterprise-grade engineering conventions using a dual-layer knowledge architecture:

  • Layer 1 — Vector RAG: Curated ruleset across Git branching, test isolation, file taxonomy, and safety protocols stored in ChromaDB/Pinecone. Top-5 relevant rules injected dynamically per task.
  • Layer 2 — Fine-Tuned Model: LoRA fine-tune on Llama 3.1 8B / Mistral 7B trained on real-world PR reviews and code smells, benchmarked with RAGAS metrics (precision, recall, latency).

Human-First Disambiguation: When a flagged item might be intentional, Scoupe asks the developer first (zero AI cost). Only if the developer is unsure does it escalate to semantic inference.

INNOVATION 06ECOSYSTEM

6. 📦 Scoupe Kit — Curated Vibe Coder Bundle

A turnkey one-command initialization suite that outfits any AI coding workspace:

npx scoupe-kit init

Configures and deploys Graphiti MCP (temporal knowledge graph replacing 15-file scans with single 200-token queries), codebase-memory-mcp (AST symbol index up to 120x compression), plus filesystem, git, and puppeteer MCPs.

Hope-Based Documentation
